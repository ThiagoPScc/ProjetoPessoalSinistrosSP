# 🚦 Sinistros SP

### Análise estatística e geográfica de acidentes de trânsito em São Paulo

> Projeto de análise de dados desenvolvido para investigar, de forma integrada, os acidentes de trânsito no estado de São Paulo, explorando características das ocorrências, vítimas, veículos, localização geográfica e gravidade dos acidentes.

---

## 📌 Sobre o projeto

Acidentes de trânsito fazem parte do cotidiano de São Paulo, porém as informações sobre eles muitas vezes são apresentadas de forma fragmentada.

A partir disso, surgiu a ideia de reunir e analisar os dados de acidentes de trânsito disponibilizados pelo **DETRAN**, buscando construir uma visão mais ampla do problema.

O projeto investiga diferentes aspectos dos acidentes, como:

- 👥 Perfil das vítimas
- 🚗 Veículos envolvidos
- 📍 Distribuição geográfica dos acidentes
- 🗺️ Distribuição pelas zonas de São Paulo
- 📅 Dias e períodos com maior ocorrência
- ⚠️ Gravidade dos acidentes
- ⚰️ Número de óbitos
- 📊 Relações entre diferentes características dos acidentes

O projeto foi desenvolvido como uma forma de consolidar conhecimentos de **Ciência de Dados, Business Intelligence, análise exploratória, ETL, SQL e análise geográfica**, passando desde a exploração inicial dos dados até a construção de um dashboard interativo.

---

# 🎯 Objetivos

O principal objetivo é compreender melhor o cenário dos acidentes de trânsito em São Paulo através da análise dos dados.

Algumas das perguntas investigadas durante o projeto foram:

- Quem são as principais vítimas dos acidentes?
- Quais tipos de veículos estão mais envolvidos?
- Quais zonas concentram mais acidentes?
- Em quais dias e períodos os acidentes são mais frequentes?
- Qual é a gravidade dos acidentes?
- Quantas vítimas são registradas?
- Como os acidentes se distribuem geograficamente?
- Existem padrões que podem ser identificados através dos dados?
